# ITCoreNet – neue Website

Dieses Repository enthält die neue Website von ITCoreNet (itcorenet.com).

**Aktueller Stand: Text- und Konzeptphase.** Es gibt noch keinen Code und nichts davon ist online.
Die bestehende Website wird erst nach ausdrücklicher Freigabe ersetzt.

## Inhalt

| Ordner / Datei | Inhalt |
|---|---|
| `inhalte/KONZEPT.md` | Abgestimmte Entscheidungen: Positionierung, Leistungen, Seitenstruktur, Technik |
| `inhalte/OFFENE-PUNKTE.md` | Was noch bestätigt oder geprüft werden muss |
| `inhalte/de/` | Texte aller deutschen Seiten (Entwurf) |
| `inhalte/en/` | Texte aller englischen Seiten (Entwurf) |

Jede Textdatei beginnt mit einem Kopfbereich (zwischen `---`) mit Seitentitel, Beschreibung für
Suchmaschinen und Adresse der Seite. Darunter steht der sichtbare Seitentext.

Markierungen in den Texten:

- **[OFFEN]** – Information fehlt oder muss bestätigt werden
- **[OPTIONAL — REQUIRES OWNER CONFIRMATION]** – zusätzlicher Inhalt, nur nach Freigabe
- **[RECHTLICHE PRÜFUNG EMPFOHLEN]** – Formulierung sollte juristisch geprüft werden

Eine ausführliche Anleitung (lokal starten, bauen, auf IONOS hochladen, zurückrollen) folgt mit
der Umsetzung.
