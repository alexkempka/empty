# Kontakt

Beschreiben Sie kurz Ihr Vorhaben oder Ihre Frage. Sie erhalten eine Rückmeldung per E-Mail.

**E-Mail:** support@itcorenet.com

## Kontaktformular

| Feld | Pflicht | Hinweis im Feld |
|---|---|---|
| Name | ja | |
| Unternehmen | nein | |
| E-Mail-Adresse | ja | |
| Nachricht | ja | Worum geht es? |

Schaltfläche: **Nachricht senden**

Hinweis unter dem Formular:
> Ihre Angaben werden ausschließlich zur Bearbeitung Ihrer Anfrage verwendet und per E-Mail an
> ITCoreNet übermittelt. Weitere Informationen finden Sie in der
> [Datenschutzerklärung](/de/datenschutz/).

## Fehlermeldungen

- Bitte geben Sie Ihren Namen ein.
- Bitte geben Sie eine gültige E-Mail-Adresse ein.
- Bitte geben Sie eine Nachricht ein.
- Ihre Nachricht ist zu lang. Bitte kürzen Sie sie auf höchstens 5.000 Zeichen.
- Die Nachricht konnte nicht gesendet werden. Bitte versuchen Sie es später erneut oder schreiben
  Sie direkt an support@itcorenet.com.
- Sie haben in kurzer Zeit mehrere Nachrichten gesendet. Bitte versuchen Sie es in einigen Minuten
  erneut.
